# App Authentication

Starter workspace with a React + TypeScript frontend in `client` and an Express + TypeScript backend in `server`.

## Workspace scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Frontend

```bash
cd client
npm run dev
```

## Backend

```bash
cd server
npm run dev
```

## Build

```bash
cd client
npm run build

cd ../server
npm run build
```
